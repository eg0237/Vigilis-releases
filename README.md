# Vigilis — Releases

Logiciel de création et de gestion des emplois du temps en Vie Scolaire.

Ce dépôt **ne contient aucun code source** : il ne sert qu'à héberger les exécutables
publiés de Vigilis. Le code est développé dans un dépôt privé séparé.

## Téléchargement

Récupérez la dernière version de `Vigilis.exe` depuis la page
[**Releases**](https://github.com/eg0237/Vigilis-releases/releases).

Application Windows autonome : aucune installation, il suffit de lancer `Vigilis.exe`.
